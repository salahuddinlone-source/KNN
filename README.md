# K-Nearest Neighbors (KNN) Classification

## Project Overview

This project demonstrates a K-Nearest Neighbors (KNN) classification model using Python and Scikit-learn. The project covers data preprocessing, exploratory data analysis, feature scaling, model training, hyperparameter selection, and model evaluation.

## Objectives

* Clean and preprocess the dataset
* Perform exploratory data analysis
* Scale numerical features
* Build a KNN classification model
* Select an appropriate value of K
* Evaluate model performance
* Analyze classification results

## Technologies Used

* Python
* Pandas
* NumPy
* Scikit-learn
* Matplotlib
* Seaborn
* Jupyter Notebook

## Machine Learning Algorithm

### K-Nearest Neighbors

KNN is a supervised machine learning algorithm that classifies a data point based on the classes of its nearest neighboring data points.
